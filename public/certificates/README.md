# Certificates Directory

Place your certificate images (.png, .jpg, .webp) in this folder.

### Suggested File Naming:
- `degree.png` (for your BSc Degree)
- `networking-security.png`
- `itf-setting-up.png`
- `cloud-computing.png`
- `office-365.png`
- `it-ethics.png`
- `comptia-basics.png`
- `databases-dev.png`
- `ibm-cybersecurity.png`
- `ibm-cloud.png`

After placing an image here, reference it in `src/content/certifications.ts` as:
`image: "/certificates/your-image-name.png"`
